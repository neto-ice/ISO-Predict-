# ISO-Predict-

Professional football prediction website with live scores, fixtures, and high-probability odds.

## Features

- Live scores
- Today's fixtures with odds (Match Winner, Over/Under 2.5, BTTS)
- High-probability market highlighting (odds ≤ 1.80)
- Pick of the Day
- Prediction history & success rate
- Auto-refresh every 5 minutes

## How to use

1. Open `index.html` in your browser
2. Or deploy to GitHub Pages for a public link
